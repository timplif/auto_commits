# 🤖 Авто-коммиты: учебный проект по автоматизации

> Эксперимент по изучению GitHub Actions, cron-задач и автоматизации рабочих процессов. Скрипт каждый день создаёт коммиты, имитируя активность реального разработчика.

---

## 📌 О проекте

Этот репозиторий — моя песочница для изучения **DevOps-практик** и **автоматизации**. Главная цель — разобраться, как с помощью GitHub Actions можно полностью автоматизировать рутинные задачи, не запуская код на своём компьютере.

**Что умеет проект:**
- 🤖 **Автоматически создаёт коммиты** каждый день без моего участия
- 🎲 **Генерирует случайное количество** коммитов (от 1 до 10 в день)
- ⏰ **Разбрасывает коммиты по времени** — как будто я работаю с 9:00 до 21:00
- 💬 **Использует реалистичные сообщения** — `fix:`, `feat:`, `refactor:`, `docs:`
- 📅 **Ставит правильные даты** через `git commit --date`, чтобы график активности выглядел естественно
-  **Имитирует поведение человека** — разные паттерны в будни и выходные

## ⚙️ Как это работает

  schedule:
    - cron: '0 7 * * *'   # 07:00 UTC = 10:00 МСК
